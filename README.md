# Freelancehunt AI Assistant Bot 🤖🚀

Telegram-бот для мониторинга новых заказов на бирже **Freelancehunt** с анализом проектов и генерацией откликов через **Google Gemini AI**.

## Основные возможности

- **Мгновенный мониторинг**: проверка новых заказов каждые 30 секунд с отправкой карточек в Telegram-канал или чат.
- **Анализ и скоринг через Gemini AI**: оценка сложности задачи, бюджета и соответствия навыкам.
- **Генерация откликов**: создание персонализированного черновика отклика с учетом стека и языка проекта (UA/RU).
- **Фильтрация**: отсеивание нерелевантных тематик, контроль бюджетов и ключевых навыков.

## Стек технологий

- Python 3.11+
- aiogram 3.x
- aiohttp, aiosqlite
- Google Gemini API
- Docker Compose

## Установка и запуск

1. Создайте `.env` файл:
   ```env
   FH_TOKEN=ваш_api_токен_freelancehunt
   BOT_TOKEN=токен_telegram_бота
   CHAT_ID=id_канала_или_чата
   GEMINI_KEYS=ключ_gemini_1,ключ_gemini_2
   ```

2. Запустите в Docker:
   ```bash
   docker compose up -d --build
   ```
